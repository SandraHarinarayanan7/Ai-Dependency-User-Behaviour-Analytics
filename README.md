#  AI Dependency & User Behaviour Insights | Tableau

## 📌 Project Overview

This project presents an interactive AI Dependency & User Behaviour Insights Dashboard developed using Tableau to explore patterns in AI chatbot usage, user behaviour, social interaction, emotional well-being, and lifestyle factors.

The project analyzes user-level data to understand how AI usage patterns relate to loneliness, emotional attachment, sleep quality, stress, social interaction, and other behavioural indicators. The dashboard transforms raw behavioural data into meaningful visual insights through a combination of data preparation, calculated fields, exploratory analysis, and interactive visualization.

The objective of this project is to demonstrate how data analytics and visualization can be used to identify behavioural patterns and relationships within AI usage data and present them through a clear, business-oriented analytical dashboard.

---

## 🧹 Data Cleaning & Preparation

The dataset was reviewed and prepared before developing the dashboard to improve data quality and ensure consistency throughout the analysis.

Key data preparation activities included:

* Cleaning and organizing the raw dataset
  
* Identifying and treating null and missing values
  
* Checking data consistency and field validity
  
* Standardizing categorical and numerical data
  
* Reviewing data types and formatting
  
* Creating calculated and derived columns required for analysis
  
* Categorizing users based on relevant behavioural and dependency indicators
  
* Preparing the dataset for effective Tableau visualization and aggregation

The cleaned and enhanced dataset was then used as the foundation for dashboard development and exploratory analysis.

## 🔍 Key Analytical Areas

The dashboard explores several dimensions of user behaviour and AI dependency, including:

* Primary AI Use Case Distribution
* Dependency Risk Levels Across Age Groups
* Loneliness Score vs. Daily AI Chat Hours
* AI Chatbot Usage vs. Screen Time by Platform
* Exercise & Social Media Usage by Age Group
* Loneliness & Emotional Attachment by Stress Pattern

These visualizations help identify relationships between AI usage, age, stress, loneliness, social behaviour, and emotional attachment.

## 🧠 Behavioural & Dependency Analysis

A major focus of this project is understanding AI dependency patterns across different user segments.

The analysis examines:

* AI dependency risk across age groups
  
* Differences in AI usage across chatbot platforms
  
* Common primary use cases for AI chatbots
  
* Relationship between loneliness and AI chat duration
  
* Emotional attachment patterns across stress levels
  
* Human interaction compared with AI usage
  
* Relationship between lifestyle behaviour and AI dependency indicators

These analyses provide a broader perspective on how AI interaction patterns may vary according to users' behavioural and social characteristics.

## 📊 Dashboard Design & Visualization

The dashboard was designed to provide a clean, interactive, and insight-focused analytical experience.

Different visualization techniques were used to communicate patterns effectively, including:

* KPI cards for high-level metrics
  
* Pie charts for categorical distributions
  
* Stacked bar charts for age-group comparisons
  
* Scatter plots for relationship analysis
  
* Bar charts for platform comparisons
  
* Line charts for behavioural comparisons
  
* Highlight tables for stress and emotional indicators
  
* Interactive filters for dynamic data exploration

The dashboard combines these visual elements to provide both high-level summaries and deeper behavioural insights within a single analytical view.
